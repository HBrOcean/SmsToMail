# 短信验证码 → 邮箱

手机上收到短信（尤其是验证码），自动转发到你的邮箱。
两条路都可以走，**推荐先用 C 方案 5 分钟跑通，再决定要不要自建 App**。

| 方案 | 是什么 | 花费时间 | 适合 |
|---|---|---|---|
| **C · SmsForwarder（推荐先用）** | 成熟开源 App，内置「邮件」发送通道 | 5 分钟 | 想马上能用、不折腾 |
| **B · 本仓库 App** | 自己写的 Kotlin 应用，~600 行，逻辑透明 | 15 分钟（云端打包） | 想自己掌控、想改规则 |

两个方案都直接走 163 邮箱的 SMTP，**不需要任何服务器**，邮件从你手机直接发到 163 的服务器。

---

## 0. 先做一次：拿到 163 的「授权码」

无论走哪个方案，这一步都一样。**授权码不是邮箱登录密码**，是专门给客户端用的 16 位字符串。

1. 电脑浏览器登录 <https://mail.163.com>
2. 点右上角 **设置** → 左侧 **POP3/SMTP/IMAP**
3. 找到 **SMTP服务**，点「开启」（会要求短信验证 / 扫码）
4. 弹窗里会显示一串 **授权码**，复制保存好（只显示一次，丢了只能重置）

同时记住 163 的 SMTP 参数：

| 项 | 值 |
|---|---|
| 服务器 | `smtp.163.com` |
| 端口 + 加密 | `465` + SSL（推荐，最省事）<br>`587` + STARTTLS（备用） |
| 账号 | 你的完整邮箱地址 `xxx@163.com` |
| 密码 | 上一步的**授权码** |

> 163 的硬性规则：邮件头里的「发件人」必须和 SMTP 登录账号完全一致，否则报 `553`。

## C. SmsForwarder：5 分钟跑通

SmsForwarder（短信转发器）是开源项目 <https://github.com/pppscn/SmsForwarder>，
在 GitHub Releases 里下载 `SmsForwarder-x.x.x.apk` 安装（或你常用的应用市场版本）。

**1）新建发送通道**

侧边栏 / 顶部菜单 → **发送通道** → 右下 `+` → 通道类型选 **邮件**，填：

- SMTP 服务器：`smtp.163.com`
- 端口：`465`
- 是否 SSL：**开启**
- 发件邮箱：你的 `xxx@163.com`
- 授权码 / 密码：第 0 步拿到的 16 位授权码
- 收件邮箱：你想收验证码的邮箱（可以和发件同一个 163 邮箱）
- 点右上角 **测试**，收到测试邮件说明通了 → 保存

**2）新建转发规则**

回到首页 → **转发规则** → `+`：

- 匹配模式：**包含**
- 关键字：`验证码`（想更严可以再建几条：`校验码`、`动态码`、`code`）
- 指定发送通道：选刚才建的邮件通道
- 保存

**3）授权**

首次运行按提示给 **短信读取权限**；国产 ROM 再到系统设置里允许「自启动 / 后台运行」，否则息屏久了收不到广播。

之后收到含「验证码」的短信，邮箱就会收到通知。想全量转发，就把匹配模式改成「全部」或再加一条无条件规则。

## B. 本仓库 App：自己编译一份

### 代码结构

```
app/src/main/java/com/oceaniat/sms2mail/
├── SmsReceiver.kt      # 短信广播：解析 pdus、拼长短信、判断是否是验证码短信
├── CodeExtractor.kt    # 验证码提取（关键词后 4~8 位数字 → 全文唯一 4~8 位数字）
├── SendMailWorker.kt   # WorkManager 任务：断网等待、失败重试
├── MailSender.kt       # JavaMail 直连 SMTP（465 SSL / 587 STARTTLS）
├── MailConfig.kt       # 配置数据类
├── Prefs.kt            # 配置读写（应用私有目录）
├── LogStore.kt         # 最近 80 条转发记录
└── MainActivity.kt     # 配置界面 + 测试发信 + 权限申请
```

设计要点：
- **不用常驻服务**：系统收到短信会唤醒 `SmsReceiver`，入队后进程可被回收，靠 WorkManager 保证送达。
- **长短信**：一条短信被拆成多段 pdus 时会先按发件人合并，再判断/发信。
- **只发验证码类**：默认只转发命中关键词、或能提取出验证码的短信（设置里可改成「转发所有短信」）。

### 编译：不用装 Android Studio

**方式 1：GitHub Actions 云端打包（推荐，手机上就能完成）**

1. 新建 GitHub 仓库，把本目录推上去（命令见文末）
2. 打开仓库 → **Actions** → 左侧 `Build APK` → 右侧 `Run workflow`
3. 约 3~5 分钟，绿勾后进入这次运行 → 底部 **Artifacts** → 下载 `SmsToMail-apk.zip`
4. 手机上解压得到 `app-debug.apk`，允许「安装未知来源应用」后安装
5. 打 tag 会自动发 Release：
   ```bash
   git tag v1.0.0 && git push origin v1.0.0
   ```

**方式 2：本地编译**

```bash
# JDK 17 + Android SDK (platform 35, build-tools 35) 就绪后
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

Android Studio 直接 `File → Open` 本目录也可以。

### 装好之后

1. 打开「短信转邮箱」，点 **授予短信读取权限**
2. 填：
   - 发件邮箱：`xxx@163.com`
   - SMTP 授权码：第 0 步的 16 位
   - SMTP 服务器 / 端口：`smtp.163.com` / `465`（SSL 开关保持打开）
   - 收件邮箱：`yyy@163.com`（可填多个，逗号分隔）
   - 想全量转发就打开「转发所有短信」
3. 点 **发送测试邮件**，收到就说明通了
4. 去系统设置 → 应用管理 → 短信转邮箱 → 允许 **自启动 / 后台活动**（国产 ROM 建议一并打开，否则深度休眠时收不到广播）
5. 之后收到验证码短信，App 里「最近记录」会显示：收到 → 已发送（或具体失败原因）

## 常见问题

**收不到 / 不转发**
- 检查短信权限是否真的授予（界面顶部会显示 `短信权限 ✓/✗`）
- 小米/华为/OPPO/vivo 的「省电策略」「应用自启动」「后台限制」要把本 App 或 SmsForwarder 加入白名单
- 界面「最近记录」里如果没有任何条目，说明广播根本没到 → 一定是权限 / ROM 后台限制问题
- 有记录但失败，看提示：
  - `535 认证失败` → 授权码错，或 163 没开 SMTP 服务
  - `553` → 「发件邮箱」和登录账号不一致
  - `连接超时` → 端口/SSL 配对错了（465 必须开 SSL；587 必须关 SSL、开 STARTTLS，本 App 会自动处理）
- 某些国产 ROM 只允许「默认短信应用」读取短信内容，但**接收广播**普通应用也可以做，一般不受此限制

**Android 高版本的限制**
本 App 的 `targetSdk = 34`，避开了 Android 15 的强制 edge-to-edge 布局变化；
`minSdk = 24`（Android 7.0 起可用）。

**安全提醒**
授权码以明文存在 App 的私有目录（`SharedPreferences`，其他应用读不到）。
这个仓库里**不要**提交任何授权码 / keystore。App 也带了 `allowBackup=false`，避免被备份出去。

**双卡手机**
两条卡的短信都会走到同一个广播，邮件里会写清「发件人」号码，可据此区分。
